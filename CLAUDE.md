# Moat (competitor research agent)

Agent that takes a company name (+ optional URL), researches its competitors, verifies them independently, asks a human to approve, then writes a sourced Markdown report. Core promise: **traceability, not intelligence**. The model will sometimes be wrong; the system catches it, shows its work, and stops rather than guesses.

**Design/UI work → read `DESIGN.md` first (§0 for small changes). Don't invent styles.**
**Brainstorming / product decisions / "why is it like this?" → read `DECISIONS.md`. Skip it for routine edits.**

## Stack
Python 3.11+ · Gemini (`google-genai`) · Tavily search · Pydantic · Tenacity · Streamlit UI · SQLAlchemy (SQLite local, Postgres prod) · Google sign-in via Streamlit's native OIDC (`st.login`). No agent framework.
Config (env / `.env` / `st.secrets`): `GEMINI_API_KEY`, `TAVILY_API_KEY`; `DATABASE_URL` (unset = local `data/cra.db`); `KEY_VAULT_SECRET` (encrypts users' own keys; required to save them); `FREE_RUNS` (1); `UNLIMITED_EMAILS` (allow list, runs on our keys with no cap); `DAILY_RUNS_PER_USER` (3), `DAILY_RUNS_GLOBAL` (150); `OPERATOR_NAME`, `CONTACT_EMAIL`, `JURISDICTION` (legal pages); Google `[auth]` block in `.streamlit/secrets.toml` (template: `.streamlit/secrets.toml.example`); `CRA_DEV_AUTH=1` local-only sign-in bypass.

## Run
```
python main.py                                   # CLI
streamlit run moat_app.py --server.port 4000          # web UI (dev port 4000)
python run_eval.py [CaseName]                    # regression evals (live API; spends quota)
python tests/test_backend.py                     # accounts + usage-limit checks (SQLite, no network)
```
UI-only work: set placeholder `GEMINI_API_KEY`/`TAVILY_API_KEY` and `CRA_DEV_AUTH=1` (renders everything; Research fails at the API). Landing/legal pages need no keys; a research run needs them (read lazily by `config.get_gemini/get_tavily`, or the user's own keys via `use_keys`).

## Pipeline (one flow, all entry points share it)
identify → research (tool loop) → verify (separate call) → checks → human review → report
`pipeline.py` LLM steps · `tools.py` search/extract + source tracking · `evaluate.py` deterministic checks · `report.py` Markdown · `schemas.py` Pydantic outputs · `prompts.py` all prompt text · `config.py` per-run clients/model/retry (`use_keys`) · `runner.py` background research job · `keycheck.py` validates a user's own keys · `eval_cases.py` + `run_eval.py` regression cases · `main.py` CLI · `moat_app.py` Streamlit router · `views/` pages (`landing`, `tool` at `/app`, `account`, `privacy`, `terms`; `onboarding.py` = 2 questions + teammates + own keys; `auth.py` = sign-in + consent gate; `chrome.py` = left rail + footer; `session.py` = cached user) · `backend/` accounts + usage limits (no Streamlit) · `legal/*.md` Terms + Privacy text · `tests/test_backend.py`.

## Hard rules
- **Only `moat_app.py` and `views/` import Streamlit.** Pipeline, evaluate, report, tools and `backend/` stay UI-agnostic so CLI and web share them.
- UI changes never edit `pipeline.py`, `evaluate.py`, `prompts.py`, `tools.py`, `schemas.py`.
- No top bar anywhere: sign-in/consent/onboarding show only their column, signed-in pages use the left rail (`chrome.sidebar`). Never read the user from the database on every rerun; use `views/session.py` (`refresh()` after a change).
- Protected pages call `auth.require_user()` first; a research run calls `usage.try_consume()` BEFORE the pipeline (no refunds). `CRA_DEV_AUTH=1` is local-only; never set it in production.
- Landing rules: no `<` character in any CSS (the sanitizer drops the whole style block), no inline SVG (CSS masks instead), no CDN scripts (vendored under `static/vendor/`), page must be complete without JS. Details in DESIGN.md section 13 and M4.
- Store only: users, onboarding answers, daily usage, users' own API keys (encrypted by `backend/vault.py`, never in the clear) and teammate emails typed in onboarding (saved, never emailed) and `research_jobs` (a user's 10 most recent researches: working state and report text, each deleted on request, on account deletion, or after 24 h). Finished reports are NOT kept; if that changes, update `legal/privacy.md` in the same change.
- Report download = `static/download.js` (browser Blob). Never `st.download_button` (breaks across Vercel instances). Motion rules: DESIGN.md section 17.
- Research never runs inside a Streamlit page: Vercel WebSockets last under a minute and a run takes 30-90 s. `views/tool.py` starts a job (`runner.py`, background thread) and reads `backend/jobs.py`. Keys for a run come from `config.use_keys` (per job), never a module global.
- Free run: `FREE_RUNS` (1) per user for life on OUR keys; after that (or after skipping onboarding's key step) users bring their own keys. Own-key runs are not limited by us.
- Legal text change ⇒ bump `LEGAL_VERSION` in `backend/config.py` (forces re-consent). The Privacy Policy must match what we actually collect and send.
- Prompt or pipeline change ⇒ run `run_eval.py`; gates must pass. Gates = stable assertions; observations = may vary (live web), never gate on them.
- Identity unclear ⇒ stop and explain; never guess. Verifier gets the target's *scale* but not the researcher's *reasoning*.
- Sources tracked in code (tools record fetched URLs); model-cited URLs not in that record are fabricated and stripped.
- Verdicts pair to competitors by index, never by name.
- Retry only 429/5xx/transport errors; never 404.
- Never commit keys. `.env` is gitignored; `.dockerignore` must keep it out of images.

## Conventions
Python, type hints, Pydantic for every structured LLM output. Comments explain *why* (each safeguard maps to an observed failure). Prompts live only in `prompts.py`. UI: mobile-first, WCAG AA, 8px grid, no inline styles, no dark patterns (these override any generic React/Tailwind defaults: this repo is Python/Streamlit).

## Deploy
Production: Vercel (`index.py` ASGI entry, redirects sign-in and sign-out to `/app`, `pyproject.toml`, `vercel.json`, `.vercelignore`), https://moatcra.vercel.app, deploy with `vercel deploy --prod --yes`; env vars in README. Production needs `DATABASE_URL`; Vercel disk is ephemeral. Alternates below.
Docker on Render (`Dockerfile`; binds `0.0.0.0`, honors `$PORT`) and Streamlit Community Cloud (`st.secrets` bridged to env in `moat_app.py` before importing the pipeline).
