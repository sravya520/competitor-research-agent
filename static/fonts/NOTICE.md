# Fonts (self-hosted)

`instrument-sans-wght.woff2`: Instrument Sans, variable weight 400 to 700, Latin subset, from the
`@fontsource-variable/instrument-sans` npm package (v5.3.0). License: SIL Open Font License 1.1,
see `OFL-instrument-sans.txt`. Self-hosted on purpose: no Google Fonts or CDN requests (privacy).

To update: `cd design-system && npm i @fontsource-variable/instrument-sans@latest`, then copy
`node_modules/@fontsource-variable/instrument-sans/files/instrument-sans-latin-wght-normal.woff2` here
under the same name.
