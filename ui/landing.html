Before you see anything

What gets checked.

  • The right company

    Same-name companies are the most common failure. It confirms identity first.

  • Links that exist

    Any cited link the agent never fetched is treated as invented and removed.

  • Independent sources

    Two pages on one site count once. Each competitor shows how many sites back it.

  • Roundup lists

    "Best tools for X" pages are flagged and checked against each company's own site.

  • When to stop

    If it can't tell which company you mean, it says so instead of guessing.
